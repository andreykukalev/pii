# Sources And Processing Rights

[ResearchSources](../../src/Pii.Infrastructure/ResearchSources.cs) implements bounded SEC, ECB and Twelve Data adapters. Tests use recorded HTTP, not actual vendor-format/live success. No provider subscription, source rights or Foundry processing permission has been inferred from public availability.

| Source/path | Implemented coverage | Essential limits / enablement |
| --- | --- | --- |
| SEC submissions | CIK/ticker-checked recent filing metadata, accession/acceptance or conservative NY date-end publication, up to 20 events | Explicit identified agent/contact and separate rights; recent list only, no older-file pagination or comprehensive journalism |
| SEC companyfacts | A bounded set of reported US-GAAP revenue/income/assets/liabilities/cash fields with currency, period, accession and publication joins | Up to 40 facts; last 1000 entries examined per supported tag, joined to at most 1000 recent submissions; missing tags/non-US/ETF fields unavailable |
| ECB 90-day XML | EUR reference orientation, date/age, conservative next-UTC-day availability, last eligible date; automatically composed into non-EUR market quotes | Each quote uses its own `AsOf`, not the later run cutoff; no future-rate fallback, executed broker FX or coverage beyond the feed window |
| Twelve Data eod/quote/time_series | Explicit canonical symbol/MIC/currency, delayed EOD paths, raw daily history `adjust=none`, up to 30 bars | Key, endpoint entitlement, retrieval/display rights, evidence-retention approval, configured credit admission and date-only exchange timezone required |
| Twelve Data press_releases | Up to 10 dated corporate titles; excludes body HTML; generic news fallback when SEC identity/configuration is unavailable | Canonical query does not independently verify issuer; always Partial corporate-announcement coverage, not comprehensive journalism |

## Quote And FX Evidence

Market aliases and explicit `eod`, `quote`, `time_series` calls return native prices first. For non-EUR quotes, the adapter fetches the ECB XML **once per source invocation**, then selects the last eligible rate separately for every quote. A date-only ECB rate becomes available conservatively at the following UTC midnight; both its rate date and availability bound must precede or equal the quote's own `AsOf`. A rate eligible at the run cutoff but not at the quote timestamp cannot be used. No eligible rate, missing currency/rights, malformed XML or failed FX transport yields **Partial**, retaining the original native quote, price evidence and null `EurPerUnit`. Caller cancellation still propagates; a source deadline during FX yields Partial native prices. EUR prices use identity conversion `1` without an ECB call.

The existing `Quote` contract is unchanged. A converted quote's `EvidenceId` points to additive `PriceWithFxReference` evidence. The result retains the original Twelve Data `Price` evidence and ECB `FxReference` evidence. Combined trusted decimal numerics are `Close`, `UnitsPerEur`, reciprocal `EurPerUnit` and `CloseEur = Close * EurPerUnit`; they are reference valuation inputs, **not executed trade FX**. `Provenance` includes canonical instrument/currency, `priceEvidenceId`, `fxEvidenceId`, quote timestamp, ECB availability bound and rate date. Combined publication equals quote `AsOf`; model-processing permission requires **both** original sources' approval. References are provenance text, not new typed foreign keys; downstream withdrawal must also invalidate combined/embedded evidence.

## Bounded Retrieval

[ResearchHttp](../../src/Pii.Infrastructure/ResearchHttp.cs) keeps the **1 MiB decompressed response limit** for submissions, ECB and all Twelve Data endpoints, with a shared 20-second deadline per source invocation, approved HTTPS hosts, redirects disabled and public-IP/SSRF controls. Only a canonical SEC `/api/xbrl/companyfacts/CIK##########.json` URL can receive a separately configured larger limit. Companyfacts defaults to 1 MiB; a value above that requires explicit larger-response approval and cannot exceed **8 MiB (8388608 bytes)**. Invalid or unapproved companyfacts limits fail before either SEC request. Both declared Content-Length and streamed bytes are bounded. This is a response-size bound, not an 8 MiB total-process-memory promise: JSON materialization and buffers add memory, default JSON depth remains 64, and iteration/output are separately bounded. No full-response/large-issuer coverage claim is established by offline tests.

One invocation submits at most one paid request. SEC financial retrieval uses at most two HTTP requests; non-EUR market retrieval uses one paid request and one ECB request, including history. There are no adapter application retries or per-bar FX HTTP calls. Existing orchestration limits remain necessary; the adapter does not reserve their counters or pretend request counts are weighted credits.

## News Fallback

Generic `news`/`announcements` use SEC recent submissions first. Missing CIK (including an ETF without a filer mapping) or missing SEC rights/identified contact permits a separately entitled `press_releases` fallback. SEC identity mismatches, malformed responses, transport failures and empty historical coverage are not silently replaced. Explicit `submissions`/`sec-submissions` retain SEC-only behavior. The fallback still requires its own secure key, endpoint entitlement, credit and retention approval; unavailable fallback remains Unavailable, never synthetic Live news. Returned titles are Partial with SEC and issuer-verification/coverage limitations preserved.

Source code/config keys: `Pii:Sources:Sec:RightsAuthorized`, `ModelProcessingAllowed`, `UserAgent`; equivalent ECB flags; Twelve Data flags plus indexed `Entitlements` and `PII_TWELVEDATA_API_KEY`; `Pii:Sources:ExchangeTimeZones:<MIC>`. All are worker-only in the template. Rights flags authorize retrieval separately from model use. Overall Live sources also require valid authorized model runtime configuration; disabling model authorization currently disables live sources too.

## Source Configuration

Configuration is bound by [InfrastructureRegistration](../../src/Pii.Infrastructure/InfrastructureRegistration.cs) and forwarded only to the **worker** by [application stage](../../infra/stages/application.bicep), using the selected central manifest. Host settings are unchanged and default deny. Configuration paths use `:`; environment equivalents use `__`:

| Configuration Key | Worker Environment Key | Behavior |
| --- | --- | --- |
| `Pii:Sources:TwelveData:EvidenceRetentionAuthorized` | `Pii__Sources__TwelveData__EvidenceRetentionAuthorized` | Default false; explicitly affirm permission for indefinite retained evidence/title/derived history under the current implementation, not automatic expiry |
| `Pii:Sources:TwelveData:RequestCreditAuthorization:Authorized` | `Pii__Sources__TwelveData__RequestCreditAuthorization__Authorized` | Default false; separate request-credit authority |
| `Pii:Sources:TwelveData:RequestCreditAuthorization:RateCardVersion` | `Pii__Sources__TwelveData__RequestCreditAuthorization__RateCardVersion` | Required dated entitlement/rate-card reference, no inferred vendor rates |
| `Pii:Sources:TwelveData:RequestCreditAuthorization:MaximumCreditsPerRequest` | `Pii__Sources__TwelveData__RequestCreditAuthorization__MaximumCreditsPerRequest` | Required positive integer, bounds one endpoint request, not a daily allowance |
| `Pii:Sources:TwelveData:RequestCreditAuthorization:DailyMaximumCredits` | `Pii__Sources__TwelveData__RequestCreditAuthorization__DailyMaximumCredits` | Required positive integer UTC daily vendor quota, enforced atomically in shared SQL; missing/zero/negative denies |
| `Pii:Sources:TwelveData:RequestCreditAuthorization:EndpointWeights:<endpoint>` | `Pii__Sources__TwelveData__RequestCreditAuthorization__EndpointWeights__<endpoint>` | Required positive integer for each entitled `eod`, `quote`, `time_series`, `press_releases`; no default weights |
| `Pii:Sources:Sec:CompanyFactsMaximumBytes` | `Pii__Sources__Sec__CompanyFactsMaximumBytes` | Default 1048576; positive integer at most 8388608, companyfacts only |
| `Pii:Sources:Sec:CompanyFactsLargerResponseAuthorized` | `Pii__Sources__Sec__CompanyFactsLargerResponseAuthorized` | Default false; required when companyfacts bound exceeds 1048576 |

Missing rights/key/entitlement, missing retention approval, missing/zero/negative endpoint weight or either maximum, unknown rate card, and weight above the authorized per-request maximum all fail before paid I/O. A missing, inaccessible or exhausted shared credit store also denies before vendor or dependent FX HTTP. Admission records reservation ID and configured weight/maxima/rate-card provenance, **not vendor-reported charged credits**. Test weights and keys are synthetic, not provider pricing or licenses. Web binding strips credentials, entitlements and authorization. Fixture model DI uses the direct Application class, with production fixture-mode rejection unchanged.

## Shared Daily Credits

[SqlSourceCreditStore](../../src/Pii.Infrastructure/SqlSourceCreditStore.cs) implements the infrastructure-only `ISourceCreditStore`; no Application contract changes. Only worker DI registers it. Both hosts include the shared [EF model](../../src/Pii.Infrastructure/WorkspaceDbContext.cs), but web receives no credit-table grants or store. The optional ResearchSources constructor parameter preserves recorded/fixture constructor compatibility; it does not authorize Live Twelve Data calls without an explicitly supplied store. Tests inject their fake explicitly.

Each actual vendor HTTP attempt receives a fresh server-generated GUID and reserves its configured endpoint weight **before HTTP**. SQL selects the current date from `CONVERT(date, SYSUTCDATETIME())`, independently of caller clock, portfolio, cutoff or evidence date. `SourceCreditDays` keys the fixed vendor `TwelveData` and UTC date, stores a positive configured maximum and bigint consumed credits. `SourceCreditEntries` has a global GUID key, endpoint/weight/rate-card and immutable `ChargedUncertain` outcome. One workspace-wide vendor budget conservatively covers all keys used in that database; it is not a per-portfolio or credential-rotation allowance. No API key, instrument, source payload or personal data enters these rows.

A native Serializable transaction plus `UPDLOCK/HOLDLOCK` protects duplicate admission, creation and daily increments. At most three transaction attempts handle known deadlock/duplicate races, with bounded cancellation-aware backoff and five-second SQL commands inside the source deadline. No HTTP retry is performed by this adapter. Duplicate IDs return AlreadyReserved without charging again **and without permitting another HTTP request**; altered endpoint/weight/rate-card for that ID is rejected. A new actual attempt must receive a new GUID and new charge.

All accepted reservations remain consumed even after HTTP denial, malformed response, cancellation, timeout, unknown commit outcome or worker crash. There is no refund, reservation reuse, provider-billing idempotency or exact-once claim. `ChargedUncertain` describes conservative local accounting, not proof of vendor payment. Original credits are not converted into USD or added to `BudgetMonths.TotalUsd`.

An explicitly changed positive daily maximum updates the same SQL day without resetting consumption, including when the next request is denied; lowering below consumption blocks new admission. Raising the authorized maximum permits only its remaining difference. All active workers must use the same reviewed quota/config version; drain old workers during changes so stale configuration cannot reassert an old allowance. Previous UTC days and entries remain durable. Portfolio deletion has no cascade or refund effect on either daily credits or monthly USD reservations. See [schema upgrade](../operations/deployment.md).

## Activation Gaps

Twelve Data remains a **candidate code path**, not an approved vendor/tier. Financial-statements/statistics and detailed global ETF endpoints must not be assumed included in a low-priced tier; no silent upgrade/purchase is allowed. Actual exchange/field coverage, after-tax cost, private display/analysis/retention rights and hosted-LLM processing must be verified against the entitled subscription.

Shared daily admission is implemented and tested against disposable LocalDB; actual Azure SQL identity access, vendor response/usage, minute-rate limits and approved quota/rate-card accuracy remain unverified. The application UTC day may not match a vendor's quota reset timezone. Set a conservative reviewed daily limit and respect separate per-minute/vendor/account restrictions; this ledger is not a provider rate limiter or total billing cap.

**Caching and retention lifecycle are incomplete.** No source cache, TTL enforcement, termination deletion or cross-report/combined-evidence withdrawal was added. `EvidenceRetentionAuthorized` must affirm permission for the current indefinite retained evidence/title/derived-history behavior; it is not a deletion scheduler or verified compliance system. Leave it false if the applicable rights require a finite TTL or an unavailable automated expiry/withdrawal control. The main persistence/integration owner must implement those controls before enabling such rights. No cache freshness, automatic expiry or termination-compliance claim is made. Retrieval does not automatically grant model processing; combined evidence must never loosen either source's rights.

Use a bounded real candidate catalog (max 32) with canonical ID, Symbol, Exchange/MIC, Currency, Kind, Sector and optional Cik; exclude separately by canonical ID. Holdings and candidates do not imply Revolut eligibility. Never seed SAMPLE/OTHER or Synthetic sectors into Live production. Actual instrument/exchange/fund coverage and fund fees/composition remain evidence gates.
